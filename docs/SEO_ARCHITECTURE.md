# Next.js SEO Architecture & Vercel Indexing Prevention

This document explains the SEO infrastructure used across the alfo.online ecosystem to ensure custom domains (like \`resumeforge.alfo.online\`) rank correctly, while auto-generated deployment domains (like \`*-git-main-username.vercel.app\`) are blocked from search engines to prevent duplicate content penalties.

## BEFORE vs AFTER

### BEFORE (The Problem)
- **Hardcoded URLs:** \`metadataBase\`, \`sitemap.ts\`, and \`robots.ts\` pointed to hardcoded domains, making it difficult to clone and launch new tools without a fragile find-and-replace process.
- **Vercel Indexing:** Vercel automatically creates preview and production URLs (e.g., \`https://alfo-palette-generator.vercel.app\`). Without intervention, Google indexes these alongside the custom domain, splitting SEO authority and triggering duplicate content penalties.
- **Fractured Metadata:** Titles, descriptions, and Open Graph configurations were duplicated across files.

### AFTER (The Solution)
- **Centralized \`config/site.ts\`:** A single source of truth for the site name, description, and base URL. It dynamically resolves the correct URL based on environment variables (\`NEXT_PUBLIC_SITE_URL\` > \`VERCEL_PROJECT_PRODUCTION_URL\` > Localhost).
- **Vercel Indexing Prevention:** A Next.js middleware (\`middleware.ts\`) checks the incoming request hostname. If it contains \`.vercel.app\`, it automatically attaches the \`X-Robots-Tag: noindex, nofollow\` HTTP header.
- **Dynamic SEO Entities:** \`sitemap.ts\`, \`robots.ts\`, and `layout.tsx` use the centralized \`siteConfig\` to generate metadata and JSON-LD schema dynamically.

## Why These Fixes Matter

1. **Duplicate Content Penalty Avoidance:** Google heavily penalizes sites that serve the exact same content on multiple domains. By using the \`X-Robots-Tag\` HTTP header in Middleware, we guarantee that Googlebot drops the \`.vercel.app\` URL before it even reads the HTML.
2. **Canonicalization:** Setting \`metadataBase\` correctly ensures that all relative \`canonical\` links generated by Next.js resolve to your preferred custom domain.
3. **Scalability:** When launching the next tool (e.g., \`unitflow.alfo.online\`), you only need to change \`NEXT_PUBLIC_SITE_URL\` in the Vercel dashboard and update \`config/site.ts\`. The entire SEO structure adapts automatically.

## Architecture & Folder Structure

\`\`\`
├── config/
│   └── site.ts           # Centralized environment-based URL & metadata config
├── middleware.ts         # Injects X-Robots-Tag for .vercel.app hostnames
├── app/
│   ├── layout.tsx        # Uses siteConfig for metadata, OG, Twitter, and JSON-LD
│   ├── sitemap.ts        # Dynamically loops through content, uses siteConfig.url
│   └── robots.ts         # Generates rules, blocking indexing if on a Vercel domain
└── data/
    └── seo-content.json  # Data source for programmatic pages
\`\`\`

## Deployment & Verification Checklist

### 1. Vercel Configuration
- [ ] Add your custom domain to the Vercel project settings.
- [ ] In Vercel Environment Variables, set \`NEXT_PUBLIC_SITE_URL\` to your custom domain (e.g., \`https://resumeforge.alfo.online\`). Ensure it includes \`https://\`.
- [ ] Deploy the application.

### 2. Testing Commands / Local Verification
You can verify the middleware behavior locally by overriding the \`Host\` header using \`curl\`:

\`\`\`bash
# Start your local server
npm run build && npm run start

# Test custom domain (Should NOT have X-Robots-Tag)
curl -I -H "Host: resumeforge.alfo.online" http://localhost:3000/

# Test Vercel domain (SHOULD have X-Robots-Tag: noindex, nofollow)
curl -I -H "Host: my-project.vercel.app" http://localhost:3000/
\`\`\`

### 3. Google Search Console Validation Steps
Once deployed to production:
1. Open Google Search Console.
2. Ensure you have verified the **Domain Property** for \`alfo.online\` (or the specific subdomain).
3. Use the **URL Inspection Tool** at the top.
4. Paste the \`.vercel.app\` URL of your deployment.
   - Click "Test Live URL".
   - Under "Indexing", verify it says "Excluded by 'noindex' tag".
5. Paste your custom domain URL (e.g., \`https://resumeforge.alfo.online\`).
   - Click "Test Live URL".
   - Ensure it is "URL is available to Google" and the canonical points to the custom domain.
6. Submit your sitemap: Go to "Sitemaps" in the left menu and submit \`https://[your-custom-domain]/sitemap.xml\`.
