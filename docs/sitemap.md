# Resume-Builder Sitemap

This sitemap outlines the page structure of the Resume-Builder application, focusing on the core utility and the SEO content engine.

## 1. Core Application
- `/` - Homepage (Hero, Features, CTA)
- `/builder` - The main single-page resume editor and live preview.
- `/ats-checker` - Standalone ATS score checker (optional later, but integrated into builder for MVP).

## 2. Template Gallery
- `/templates` - Main gallery of resume templates.
- `/templates/[slug]` - Individual template details and examples.
